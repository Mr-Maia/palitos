# Aponta no Mapa

Jogo de mapas pensado para telemóvel. Escolhe Portugal (18 distritos) ou um continente e toca no sítio que aparece em baixo:

- verde — acertaste à primeira
- amarelo — 2 a 3 tentativas
- vermelho — mais de 3

Site estático, sem build: abre `index.html` através de um servidor (`python3 -m http.server`).

Dados: distritos de [click_that_hood](https://github.com/codeforgermany/click_that_hood), países de [world-atlas](https://github.com/topojson/world-atlas) e nomes/continentes de [mledoze/countries](https://github.com/mledoze/countries).
